# Ventas de una tienda ficticia (SQL)

Análisis de ventas por categoría y mes sobre una base de datos de ejemplo.

## Decisiones y limitaciones
Decisiones de modelado: tabla de hechos de pedidos y dimensiones de producto y cliente (modelo en estrella).
Supuestos: los pedidos cancelados se excluyen. Limitaciones: solo 12 meses de histórico.

## KPI
Ingresos, ticket medio y margen por categoría, pensados para la pregunta de negocio «¿qué categorías conviene potenciar?».
